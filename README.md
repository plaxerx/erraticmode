# ErraticMode

A new game mode for [Balatro](https://www.playbalatro.com/) added to the Challenges 
tab that rolls you a random deck, a random stake, a random sleeve (if CardSleeves is installed),
and up to eight **mutations** that alter the game in new an interesting ways!

**In Open Alpha.** The mutation pool has not been heavily vetted or had a full balance pass.

## How it works

Pick from up to 8 mutations to be included in game and hit start. With 0, you just get the random
deck/stake/sleeve setup. From there, mutations are drawn from a pool of 50 in three flavors:

- **Challenges** increase run difficulty
- **Boons** give you something, sometimes objectively beneficially, sometimes with a trade-off
- **Twists** change the game rules around

Whatever you roll is readable in-game under **View Deck → Mutations**.

## Requirements

- [Steamodded](https://github.com/Steamodded/smods) `>=1.0.0~BETA-0400`
- [Lovely](https://github.com/ethangreen-dev/lovely-injector)

Optional, supported if present:

- [CardSleeves](https://github.com/larswijn/CardSleeves)
- [Talisman](https://github.com/MathIsFun0/Talisman)

## Installation

Copy the `ErraticMode` folder into your Balatro mods directory:

```
%APPDATA%/Balatro/Mods/ErraticMode/
```

## Compatibility

It adds a completely new game mode that is wholly separate from the game so there should be no conflicts.
